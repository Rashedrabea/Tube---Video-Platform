# لنشر على GitHub Pages:
1. git init
2. git add index.html
3. git commit -m "نشر الموقع"
4. git remote add origin https://github.com/yourusername/tube.git
5. git push -u origin main
6. اذهب إلى Settings > Pages > اختر main branch

✅ بعد النشر، سيكون موقعك متاحاً على: https://yourusername.github.io/tube/
